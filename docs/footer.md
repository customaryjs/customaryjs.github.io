# Footer of external links

Page has a `footer` with 4 `div` elements inside, for external links.

At any page width, there can only be two dispositions:

A) one line, with all 4 `div` elements 
- leftmost `div` hugs the left edge of the page
- rightmost `div` hugs the right edge of the page

or, 

B) two columns, each one with 2 `div` elements
- left column hugs the left edge of the page and its `div` elements align to the left
- right column hugs the right edge of the page and its `div` elements align to the right
